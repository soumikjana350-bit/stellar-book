# 📚 Book NFT Smart Contract (Soroban - Stellar)

## 📖 Project Description

Book NFT is a Soroban smart contract built on the Stellar blockchain that enables the creation, ownership, and transfer of digital books as NFTs. Each NFT represents a unique book with immutable metadata such as title, author, and owner, ensuring transparency and verifiable ownership on-chain.

---

## 🚀 What it does

This smart contract allows users to tokenize books into NFTs and manage them securely on the Stellar network.

* Mint NFTs representing unique books
* Store book metadata directly on-chain
* Transfer ownership in a secure and decentralized way
* Retrieve book details using a unique identifier
* Ensure only the rightful owner can manage their NFT

---

## ✨ Features

* 📚 **Book NFT Minting** — Create unique NFTs for books
* 👤 **Ownership Management** — Secure ownership using Stellar addresses
* 🔄 **Transfer Functionality** — Transfer NFTs between users safely
* 🔍 **On-chain Data Retrieval** — Fetch book details anytime
* 🔐 **Authorization Checks** — Only owners can transfer their NFTs
* ⚡ **Lightweight & Efficient** — Built using Soroban SDK in Rust

## ⚡ How It Works

1. A user mints a Book NFT by providing:

   * Unique ID
   * Book title
   * Author name
   * Owner address

2. The contract stores this data on-chain

3. The owner can:

   * Transfer the NFT
   * Manage ownership

4. Anyone can view book details using the ID
